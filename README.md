# ملف إنجاز وظيفي — وفاء هارون ناقرو

موقع ثابت (HTML + CSS + JavaScript) بدون خادم وبدون أي مكتبات، ولا يحتاج إلى حساب Claude أو تسجيل دخول.

## الملفات
- `index.html` — هيكل الصفحة
- `css/style.css` — التصميم (RTL، وضع فاتح/داكن تلقائي، طباعة)
- `js/app.js` — كل المنطق: السيرة الذاتية، القائمة الجانبية، الأقسام، الإضافة/التعديل/الحذف، النسخ الاحتياطي

## التشغيل في VS Code
1. ثبّتي VS Code ثم افتحي المجلد: File ‹ Open Folder.
2. ثبّتي إضافة **Live Server** (Ritwick Dey) من تبويب Extensions.
3. اضغطي بالزر الأيمن على `index.html` ثم **Open with Live Server**.
   (يمكنك أيضاً فتح `index.html` مباشرة في المتصفح بنقرتين.)

## حفظ البيانات
- تُحفظ البيانات تلقائياً في `localStorage` داخل المتصفح، تحت المفتاح `achv_v1`.
- البيانات مرتبطة بالمتصفح وبعنوان الموقع. فتح الملف مباشرة (`file://`) وفتحه عبر Live Server (`127.0.0.1:5500`) يُنشئان مخزنين منفصلين. اختاري طريقة واحدة والتزمي بها.
- لنقل البيانات: **القائمة ‹ إدارة المحتوى والإعدادات ‹ تصدير نسخة احتياطية** ثم **استعادة**.
- مسح بيانات المتصفح يحذف البيانات، فصدّري نسخة احتياطية دورياً.

## ما يعتمد على خدمات خارجية
- **خط Tajawal** من Google Fonts (رابط في `index.html`). بدون إنترنت يعود الموقع تلقائياً لخط النظام ويعمل كاملاً.
- لا شيء آخر. تمت إزالة ربط خاصية «التنزيل» الخاص بمنصة Claude واستُبدل بتنزيل عادي من المتصفح.

## PDF والطباعة
زر «طباعة / PDF» يفتح نافذة الطباعة، واختاري «حفظ كـ PDF».

## ملاحظات
- لا توجد صور أو أيقونات خارجية؛ المرفقات التي تضيفينها تُخزَّن داخل البيانات (الصور تُصغَّر تلقائياً).
- مساحة `localStorage` نحو 5 ميغابايت، فتجنبي المرفقات الكبيرة.
